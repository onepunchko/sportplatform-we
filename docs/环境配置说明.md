# 环境配置说明

本项目支持多环境配置，包括开发环境和生产环境。以下是环境配置的使用说明。

## 前端环境配置

前端小程序使用 `config/env.js` 文件管理环境配置。

### 配置文件结构

```javascript
// 环境配置，包含开发环境和生产环境
const envConfig = {
  development: {
    apiBaseUrl: 'http://localhost:5000',
    // 其他开发环境配置...
  },
  production: {
    apiBaseUrl: 'https://www.halocc.ggff.net',
    // 其他生产环境配置...
  }
};
```

### 切换环境

前端环境切换是通过本地存储实现的：

```javascript
// 切换到开发环境
const { switchEnv } = require('../../config/env');
switchEnv('development');

// 切换到生产环境
switchEnv('production');
```

切换环境后需要重启小程序才能生效。

### 获取当前环境配置

```javascript
const { getConfig } = require('../../config/env');
const config = getConfig();
console.log(config.apiBaseUrl); // 当前环境的API地址
```

## 后端环境配置

后端使用 `.env` 文件管理环境变量，并通过 Python-dotenv 库加载。

### 环境配置文件

项目中包含以下环境配置文件：

- `env.example` - 配置模板，新开发人员可基于此创建自己的配置
- `scripts/env.development` - 开发环境配置
- `scripts/env.production` - 生产环境配置

### 切换环境

使用提供的脚本切换环境：

```bash
# 切换到开发环境
python scripts/switch_env.py development

# 切换到生产环境
python scripts/switch_env.py production
```

### 创建自定义环境配置

1. 复制 `env.example` 文件并重命名为 `.env`
2. 根据需要修改配置值
3. 重启应用以应用新配置

### 重要配置项说明

- `FLASK_ENV` - 环境名称，可以是 `development` 或 `production`
- `DEBUG` - 是否启用调试模式
- `DATABASE_URL` - 数据库连接URL
- `SECRET_KEY` 和 `JWT_SECRET_KEY` - 安全密钥，生产环境应使用强密钥
- `HOST` 和 `PORT` - 服务器绑定的主机和端口
- `CORS_ORIGINS` - 允许跨域请求的源，用逗号分隔

## 注意事项

1. 不要将包含敏感信息的 `.env` 文件提交到版本控制系统
2. 生产环境必须使用强密钥和安全的数据库凭据
3. 开发人员应根据 `env.example` 创建自己的本地环境配置
4. 环境切换后，确保重启应用以应用新配置
