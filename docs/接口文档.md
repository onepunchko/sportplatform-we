# 运动平台API接口文档

## 1. 资讯模块

### 1.1 获取资讯列表
- 接口核心功能描述：获取平台资讯列表，支持分类筛选和关键词搜索
- 接口地址: /news/list
- 方法: POST
- 需要登录: 否
- 请求参数: 
  ```json
  {
    "category": "string", // 可选，资讯分类ID
    "keyword": "string"   // 可选，搜索关键词
  }
  ```
- 响应类型: JSON
- 返回值：
  ```json
  {
    "error": 0,
    "body": [
      {
        "id": 1,
        "title": "校园马拉松月底开跑，请各位运动员提前报名",
        "image": "https://example.com/image.jpg",
        "source": "校园体育部",
        "date": "2023-05-13",
        "views": 1245,
        "content": "今年校园马拉松将于5月30日举行，参赛选手需要提前两周报名，并参加赛前培训..."
      }
    ],
    "message": ""
  }
  ```

## 2. 用户模块

### 2.1 用户登录
- 接口核心功能描述：用户登录系统，获取身份凭证token
- 接口地址: /user/login
- 方法: POST
- 需要登录: 否
- 请求参数: 
  ```json
  {
    "username": "string", // 用户名
    "password": "string"  // 密码
  }
  ```
- 响应类型: JSON
- 返回值：
  ```json
  {
    "error": 0,
    "body": {
      "token": "string", // 登录token
      "userId": "string", // 用户ID
      "expireTime": "number" // token过期时间
    },
    "message": ""
  }
  ```

### 2.2 获取用户信息

  ```json
  {}
  ```

  ```json
  {
    "error": 0,
  ```

  ```json
  {}
  ```

  ```json

    "error": 0,
  ```

  ```json
      "startTime": "string", // 开始时间
  ```
